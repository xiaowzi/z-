# z-boson
从原始双电荷粒子动量学中学习Z玻色子质量窗口规则:基:于公开CMS开放数据的轻型神经网络架构控制基准测试
根据双轻子事件的不变质量是否落在Z玻色子质量窗口内对其进行分类，是强子对撞机中一项常见的操作。我们将这一任务视为一个二元分类问题，仅使用八个原始的单轻子运动学观测量(每个轻子的横动量、赝快度、方位角和电荷)，并评估PAResFCN一一一个具有53,886个可训练参数的轻量级特征门控残差全连接网络，同时结合普通与门控控制以及经典基线方法(固定配置加一个验证集调优的梯度提升)。实验遵循泄漏控制协议，使用一个包含20,000条CMS衍生记录的公开样本(经过正反电荷选择后为17,255条):输入中排除了运行和事件标识符，不变质量仅用于构建标签且从不进入模型，标度器仅在训练数据上拟合，阈值仅在验证数据上选择。标签编码的是质量窗口归属，这是输入运动学量的确定性函数，而非真实的物理过程，因此该研究是对学习已知解析映射的一个受控基准测试。群体层面的审计显示，所有保留的记录均为单例事件组，且各分割之间无重叠。在基于CPU的统一五分割评估中，神经模型明显超越了测试的经典基线(PA-ResFCN:90.26%准确性，92.67% F1,0.9651AUC)。然而，在参数数量匹配的情况下，普通MLP达到了最高的平均AUC(0.9767)，且证据并未证明门控残差组合具有优势;门控隔离控制表明，在这个小型骨干网络上;学习到的门控机制没有明显的额外益处(Gate-FCN减去NoGate-FCN的AUC为-0.0002，探索区间[-0.0016,0.0010】)。代码、审计输出和每个种子的预测结果均已提供，以支持独立复现。
